# Изменения

## 21 октября 2026

- Автоматическое скачивание Chromium при отсутствии Chrome и Edge.
- Повторное использование загруженного браузера; сообщение при ошибке установки.
- Регрессионные тесты выбора браузера и ошибок скачивания.

## Подготовка публичной версии

- Проверка данных карточки перед отметкой о завершении; повтор временной ошибки.
- Подтверждение перехода по ответу 2GIS для нужного номера страницы и совпадению ID.
- Фильтрация рекламных редиректов, нормализация ID и объединение контактов без потерь.
- Бэкап после каждой страницы с параметрами поиска и точной позицией.
- Поддержка старых Excel, безопасное чтение ID, защита от формул и случайной перезаписи.
- Запись Excel одним проходом; pandas больше не требуется.
- Playwright 1.64.0: проверена совместимость с Chrome 155 и корректное закрытие браузера.
- Остановка по закрытию окна, повтор сохранения в другую папку после ошибки.
- Настройки и ротация журналов в профиле пользователя; запуск независимо от текущей папки.
- Светлый интерфейс, проверки формы и доступные состояния элементов.
- Тесты ядра и браузера, CI для трёх ОС и ручной workflow сборки Windows.
