# Интерфейс Scraper 2GIS

Настольный рабочий инструмент для поиска организаций в 2GIS и сохранения
контактов в Excel. Оформление помогает настроить запрос и следить за сбором.

Светлая тема: фон #f4f5f7, панели #ffffff, текст #202632,
вторичный текст #667080, границы #e4e7ed. Синий #335cdb используется
для запуска и активного состояния, зелёный #226342 — для сохранённого
результата, красный #ad3636 — для ошибок и остановки.

Системный шрифт платформы, базовый размер 14px, вспомогательные подписи
не меньше 12px. Постоянные подписи над полями. SVG-иконки одного веса.

На широком экране настройки слева (320px), счётчики и журнал справа.
До 900px настройки сужаются; до 650px блоки идут одной колонкой.
Без градиентов, прозрачного стекла, декоративных анимаций и эмодзи.
Индикатор активности пульсирует только при сборе; reduced-motion отключает его.

Во время сбора параметры и выбор файлов недоступны. После остановки
кнопка показывает ожидание сохранения. Сохранённый файл отображается
встроенным уведомлением с кнопкой «Открыть Excel», без модального окна.
Ошибки формы выводятся рядом с кнопкой запуска и связываются с полями
через aria-invalid. Журнал добавляет данные через textContent.

Контракт с Python сохранён: имена callback-функций и ID полей прежние.
Проверки интерфейса: python tests/check_ui.py и python tests/check_logs.py.
