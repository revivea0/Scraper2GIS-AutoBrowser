# Перед публикацией

Готово локально:

- Лицензия MIT согласована автором и добавлена.
- Нет пользовательских Excel, конфигурации, логов и ключей в архиве исходников.
- Тесты ядра, браузерных сценариев и интерфейса выполнены на macOS / Python 3.12.
- Живой сбор и восстановление проверены отдельно; подробности — в TEST_REPORT.md.
- Подготовлены GitHub Actions Tests и Build Windows. Они ещё не запускались на GitHub.

Порядок выпуска:

1. Загрузить исходники в репозиторий; дождаться зелёного Tests.
2. Запустить Build Windows вручную; скачать артефакт и распаковать целиком.
3. На Windows с Chrome/Edge и WebView2 проверить запуск, выбор папки,
   несколько страниц сбора, остановку, восстановление и открытие Excel.
4. Убедиться, что закрытие окна во время сбора сохраняет файл,
   а при недоступной папке можно выбрать другую и повторить сохранение.
5. Только после ручной проверки приложить Windows-архив к GitHub Release.

Публикация на GitHub и запуск Actions из этой сессии не выполнялись:
доступ к репозиторию отсутствовал. Windows EXE на macOS не собирался
и не объявляется проверенным. Тесты не гарантируют неизменность 2GIS.

- На чистой Windows без Chrome/Edge проверить автоскачивание Chromium, повторный запуск без скачивания и ошибку при недоступном интернете.
