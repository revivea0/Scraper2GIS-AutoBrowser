Scraper 2GIS

Windows: распакуйте архив целиком. Запустите Scraper2GIS/Scraper2GIS.exe.
Не перемещайте EXE отдельно от папки _internal. Нужен Edge WebView2 Runtime.

macOS: распакуйте архив. Перенесите Scraper2GIS.app в «Программы».
Выберите архив для своего процессора: arm64 — Apple Silicon, x64 — Intel.
Приложение не подписано и не нотарифицировано Apple. macOS может заблокировать
первый запуск; разрешайте его в настройках безопасности только если доверяете источнику.

Linux x64: распакуйте tar.gz. Запустите Scraper2GIS/Scraper2GIS.
Нужен рабочий стол X11/Wayland. Сборка рассчитана на Ubuntu 24.04 и совместимые системы.

Укажите город и рубрику, выберите папку и нажмите «Начать сбор».
Если нет Chrome/Edge, Chromium скачается автоматически. Нужен интернет.
Python отдельно устанавливать не требуется.

Результат — Excel (.xlsx). Бэкап обновляется после каждой страницы.
Для остановки нажмите «Остановить и сохранить». Для продолжения выберите бэкап.
Не завершайте процесс принудительно до сохранения данных.

2GIS может изменить сайт или ограничить доступ; CAPTCHA не обходится.
Проект не является официальным приложением 2GIS.
