Сбор контактов 2GIS в Excel. Chromium скачивается автоматически, если Chrome и Edge отсутствуют. Python устанавливать не нужно.

| Файл | Устройство |
| --- | --- |
| `Windows-x64.zip` | Windows 10/11, Intel/AMD x64 |
| `macOS-arm64.zip` | Mac с Apple Silicon, macOS 15+ |
| `macOS-x64.zip` | Mac с Intel, macOS 15+ |
| `Linux-x64.tar.gz` | Linux x64, Ubuntu 24.04 и совместимые |

Распакуйте архив целиком. Инструкция `START.txt` и лицензия находятся внутри. Файлы `.sha256` содержат контрольные суммы.

Сборки не подписаны цифровой подписью; macOS может заблокировать первый запуск. Windows требует Edge WebView2 Runtime. Для первого скачивания Chromium нужен интернет.

Пакеты проходят автоматическую проверку загрузки интерфейсного backend и встроенного Playwright. Ручная проверка на всех устройствах не выполнялась. Полнота выдачи зависит от 2GIS; CAPTCHA и ограничения доступа останавливают сбор.
