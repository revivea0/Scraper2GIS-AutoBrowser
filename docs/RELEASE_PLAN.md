# Подготовка Scraper 2GIS к публикации

1. Проверить исходный Excel только для чтения и замерить пять страниц живого поиска.
2. Устранить пропуски: ID считается обработанным после ответа, карточки и страницы
   проверяются по ID, временная ошибка повторяется, неудавшаяся страница не пропускается.
3. Заменить паузы ожиданием событий; писать Excel за один проход без pandas.
4. Сохранять параметры поиска и точную позицию в бэкапе после каждой страницы;
   поддержать старые Excel, не перезаписывать исходный файл восстановления.
5. Проверить реальный браузер на управляемом сайте с задержками, ошибками,
   пустой выдачей и несколькими страницами; затем повторить живые прогоны и замер.
6. Проверить закрытие окна, конфигурацию пользователя, независимость от cwd;
   подготовить README, CI и сборку Windows без обещаний непроверенного EXE.

Границы: обычный браузер, без обхода CAPTCHA и скрытых ключей API. Приватные
выгрузки, конфигурация и диагностические файлы не попадают в архив исходников.
