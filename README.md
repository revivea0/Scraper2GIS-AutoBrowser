# Scraper 2GIS

Настольное приложение для сбора контактов организаций из видимой выдачи 2GIS
и сохранения в Excel. Поиск по городу, рубрике или названию, району и улице.

Приложение открывает отдельное окно браузера, собирает карточки и показывает
ход работы. Фиксированных пауз между карточками нет: следующая обрабатывается
после получения ответа предыдущей. Сбор последовательный, без агрессивных
параллельных запросов.

## Запуск из исходников

Нужен Python 3.10–3.12. Google Chrome или Microsoft Edge используются, если установлены.
Для разработки и сборки рекомендуется Python 3.12.

```sh
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

macOS:

```sh
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows также нужен Microsoft Edge WebView2 Runtime для окна интерфейса.
Если Chrome и Edge недоступны, приложение использует Chromium. Если Chromium
ещё не установлен, оно автоматически скачает его при первом сборе. Нужны
интернет и место на диске; установка может занять несколько минут. При ошибке
загрузки проверьте соединение и повторите сбор. Это работает и в Windows EXE. Linux требует установки
GUI-зависимостей pywebview и пока не проверялся на реальном рабочем столе.

## Работа

1. Укажите город и рубрику или название организации.
2. При необходимости выберите район или улицу и заполните её название.
3. Выберите папку для Excel. По умолчанию — `Documents/Scraper2GIS` в домашней папке.
4. Нажмите «Начать сбор». Дождитесь завершения или нажмите «Остановить и сохранить».
5. Откройте результат кнопкой «Открыть Excel».

Если закрыть приложение во время сбора, оно запросит остановку и закроется
после сохранения. Принудительное завершение процесса или отключение питания
позволяет восстановиться из последнего полностью записанного бэкапа;
текущая незавершённая страница может потребовать повторного сбора.

Если сохранить Excel не удалось, данные остаются в памяти и появляется
кнопка «Сохранить в другую папку». Новый сбор недоступен до сохранения.
Не завершайте процесс принудительно, пока нужные данные не сохранены.

## Excel и восстановление

Столбцы: ID, название, адрес, рубрики, телефоны, сайт, Telegram, ВКонтакте,
ссылка 2GIS. ID сохраняются текстом. Несколько контактов объединяются без
повторов. Текст из карточек не превращается в формулы Excel.

`BACKUP_город_рубрика.xlsx` обновляется после каждой обработанной страницы.
В скрытом листе `_scraper` записываются параметры поиска, номер страницы и
признак её полного завершения. Запись идёт во временный файл, который
заменяет бэкап только после успешного сохранения. Не удаляйте скрытый лист.

Чтобы продолжить, нажмите «Продолжить из файла» и выберите бэкап или
`STOPPED_...xlsx`. Для новых файлов параметры поиска должны совпадать
с исходными. Переименование такого файла не сбрасывает позицию.
Уже полученные ID пропускаются, незавершённая страница повторяется.
Исходный файл восстановления не перезаписывается.

Поддерживаются старые выгрузки: `BACKUP_page_N_...xlsx` продолжает с N+1,
`STOPPED_page_N_...xlsx` — с N, обычный файл — с первой страницы.
Старые файлы не содержат параметров поиска: проверьте их самостоятельно.
Длинные ID, уже округлённые Excel при записи числом, восстановить нельзя.
Итоговые результаты существующих запусков не перезаписываются: добавляется
суффикс `_2`, `_3` и т. д. Не используйте файл бэкапа, пока он записывается.

## Ограничения

2GIS меняет выдачу, порядок карточек и интерфейс. Восстановление по номеру
страницы не создаёт снимок каталога: переместившиеся на предыдущие страницы
организации могут потребовать нового запуска поиска с первой страницы.
Экспорт охватывает доступную выдачу, а не гарантированно весь каталог города.
Недоступные контакты не угадываются.

При ошибке карточка повторяется один раз. Если данные не получены, сбор
останавливается и сохраняет позицию, вместо молчаливого пропуска.
При HTTP 403/429 или CAPTCHA приложение останавливается. Обхода проверки,
автоматической ротации аккаунтов или прокси нет. Используйте данные
с учётом правил источника и своей задачи.

## Настройки и диагностика

Конфигурация и журнал находятся в папке пользователя:

- Windows: `%LOCALAPPDATA%/Scraper2GIS/`;
- macOS: `~/Library/Application Support/Scraper2GIS/`;
- Linux: `$XDG_CONFIG_HOME/Scraper2GIS/` или `~/.config/Scraper2GIS/`.

Файлы: `config.json`, `scraper.log` и до двух архивов журнала.
Журнал может содержать названия организаций и локальные пути.
Перед публикацией лога удалите личные сведения. Приложение не отправляет
логи разработчику и не требует вводить ключи API или входить в аккаунт.

## Проверки

Быстрые тесты без браузера:

```sh
python -m unittest discover -s tests -v
```

Полный набор с Chromium и управляемым тестовым сайтом, без запросов к 2GIS:

```sh
python -m playwright install chromium
```

Windows PowerShell:

```powershell
$env:SCRAPER_BROWSER_TESTS = "1"
python -m unittest discover -s tests -v
```

macOS / Linux:

```sh
SCRAPER_BROWSER_TESTS=1 python -m unittest discover -s tests -v
```

Проверки интерфейса:

```sh
python tests/check_ui.py
python tests/check_logs.py
```

GitHub Actions запускает тесты на Windows, macOS и Linux, а браузерные
сценарии — на Linux. Живой сайт в CI не используется.

## Сборка Windows

В GitHub откройте Actions → Build Windows → Run workflow. После успешной
сборки скачайте артефакт `Scraper2GIS-Windows`. Распакуйте весь архив,
запускайте `Scraper2GIS.exe` вместе с папкой `_internal`.
Сборка не подписана цифровой подписью и требует ручной проверки на Windows
перед публикацией в Releases. Автоматического выпуска или загрузки на Releases нет.

Локальная сборка на Windows:

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --onedir --windowed --name Scraper2GIS --add-data "gui:gui" --collect-all playwright --collect-all webview --recursive-copy-metadata playwright --recursive-copy-metadata pywebview --recursive-copy-metadata openpyxl main.py
```

Результат — `dist/Scraper2GIS/`. Собирать Windows EXE нужно на Windows.
Проверку доступности браузера, запуска, сбора, остановки и открытия Excel
нужно выполнить на машине будущего пользователя.
